# PRD 2.3 — Pinning UI, drag reorder, tab context menu

## Context

zeo is a keyboard-first, workspace-centric open-source browser for macOS.
Design: `docs/specs/2026-08-30-zeo-v1-design.md`. Requires PRD 2.2
(`prds/2.2-sidebar-live-tabs.md`) merged: sidebar renders pinned/unpinned
sections with live titles/favicons, and the bridge already exposes `pin`,
`unpin`, `reorder`, `archive`, `restore`.

## Deliverables

### 1. Drag reorder

- Sidebar tabs are draggable within their section (pinned stays pinned,
  unpinned stays unpinned); dropping calls `reorder` over the bridge.
- Use native HTML drag-and-drop or pointer events; no drag-and-drop
  library.
- Visual drop indicator between rows.

### 2. Pin/unpin affordances

- Dragging a tab across the section boundary pins/unpins it.
- Context menu (below) offers Pin/Unpin.

### 3. Tab context menu

- Right-click on a tab row opens a native Electron `Menu` built in the main
  process (renderer sends tab id + screen position over a new IPC channel).
- Items: Pin/Unpin, Archive, Close, Copy URL. Archive is disabled on pinned
  tabs.
- Menu actions dispatch through the same store operations and broadcast.

### 4. Tests

- e2e: reorder two tabs via mouse drag and assert the new order renders;
  pin via context menu is not automatable across the native menu — instead
  assert the menu-open IPC fires (stub in test mode) and cover pin/unpin
  through the bridge.
- Core: no new logic expected; any store change lands with unit tests.

## Constraints

- Ordering/pinning rules live in `packages/core` (already do); UI only
  dispatches.
- No new runtime dependencies without a stated reason in the MR.
- Do not create or modify anything under `.github/workflows/`; root script
  names stay unchanged.

## Acceptance criteria

- `pnpm lint && pnpm typecheck && pnpm build && pnpm test && pnpm e2e` green.
- In the running app: drag-reorder works in both sections, cross-boundary
  drag pins/unpins, right-click menu offers Pin/Unpin, Archive, Close,
  Copy URL and each works.
- CI green on the merge request branch.
