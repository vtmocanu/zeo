# PRD 3.3 — Spaces UI: switcher, management, shortcuts

## Context

zeo is a keyboard-first, workspace-centric open-source browser for macOS.
Design: `docs/specs/2026-08-30-zeo-v1-design.md`. Requires PRD 3.2
(`prds/3.2-profile-isolation.md`) merged: spaces with per-profile isolation
work end to end over the bridge; nothing is visible in the UI yet.

## Deliverables

### 1. Space switcher (renderer)

- A switcher strip in the sidebar (above the tab sections): one item per
  space showing its name, the active space highlighted. Clicking a space
  activates it; the tab sections and archived view always show the active
  space only.
- A new-space button in the strip: creates a space (name prompted inline,
  default "Space N") and activates it.

### 2. Space management (renderer + main)

- Context menu on a space item (native menu via the existing
  `showContextMenu` pattern): Rename, Delete, and a Profile submenu listing
  profiles with the space's current one checked plus a "New profile…" entry.
- Rename edits inline in the strip. Delete asks nothing when the space has no
  open or archived tabs; otherwise the menu item reads "Delete (N tabs)".
  Deleting the last space is not offered.

### 3. Keyboard shortcuts (main menu)

- `Cmd+1` … `Cmd+9` activate the Nth space (application menu accelerators,
  consistent with the existing menu wiring).
- `Cmd+Shift+N` creates a new space.

### 4. Tests

- Core: any new pure logic (space naming defaults, switcher ordering) unit
  tested in `packages/core`.
- e2e: switcher renders all spaces and highlights the active one; clicking
  switches the visible tab list; creating a space via the switcher activates
  it; renaming updates the strip; deleting an empty space removes it and
  falls back to another space.

## Constraints

- Components stay thin: state transitions live in `packages/core`, dispatch
  through the bridge; no state forked in the renderer.
- Visual style follows the existing sidebar conventions in `App.css`.
- Do not create or modify anything under `.github/workflows/`; root script
  names stay unchanged.

## Acceptance criteria

- `pnpm lint && pnpm typecheck && pnpm build && pnpm test && pnpm e2e` green.
- In the running app: spaces can be created, renamed, switched (mouse and
  `Cmd+N` shortcuts), assigned profiles, and deleted, with each space showing
  only its own tabs.
- CI green on the merge request branch.
