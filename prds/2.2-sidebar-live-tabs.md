# PRD 2.2 — Sidebar with live titles and favicons

## Context

zeo is a keyboard-first, workspace-centric open-source browser for macOS.
Design: `docs/specs/2026-08-30-zeo-v1-design.md`. Requires PRD 2.1
(`prds/2.1-tab-model.md`) merged: `TabStore` has pinning, MRU activation and
archiving, and `TabsState` carries `archived`.

Current state: `apps/desktop/src/main/index.ts` seeds tab titles once from
the url hostname (`titleForUrl`) and never updates them; no favicons exist.
`apps/ui/src/App.tsx` renders a flat tab list with new/close/activate wired
over the `window.zeo` bridge.

## Deliverables

### 1. Live titles and favicons (main process)

- On each tab's `WebContentsView`, listen for `page-title-updated` and
  `page-favicon-updated`; store the values on the tab and broadcast.
- Add `title` and `favicon` update support to `TabStore` in
  `packages/core` (e.g. `updateMeta(id, {title?, faviconUrl?})`), with unit
  tests. `Tab` gains `faviconUrl: string | null`.
- The hostname-derived title remains the fallback until the first
  `page-title-updated` arrives.

### 2. Sidebar rendering (renderer)

- Pinned section on top (compact), unpinned below, matching `list()` order.
- Each tab row: favicon (fallback glyph when null), title, close button on
  hover, active highlight.
- Tab switching via click stays; add keyboard shortcuts wired in the main
  process via Electron `globalShortcut`-free accelerators (window-scoped
  `before-input-event` or menu accelerators): Cmd+1..9 activates the Nth
  visible tab, Cmd+W closes the active tab, Cmd+T creates a new tab.
- Empty state unchanged.

### 3. IPC

Extend the preload bridge to expose the operations 2.1 typed (`pin`,
`unpin`, `reorder`, `archive`, `restore`) so the renderer can call them;
UI affordances for pin/reorder/archive are PRDs 2.3/2.4 (bridge only here,
plus the tests below).

### 4. Tests

- Core: unit tests for `updateMeta`.
- e2e: extend the Playwright suite — created tab shows hostname fallback
  title; Cmd+T adds a tab; Cmd+W closes it; the pinned section renders when
  a tab is pinned via the bridge from the test.

## Constraints

- Keep logic in `packages/core`; UI components thin; state flows only
  main → broadcast → renderer.
- Do not create or modify anything under `.github/workflows/`; root script
  names stay unchanged.

## Acceptance criteria

- `pnpm lint && pnpm typecheck && pnpm build && pnpm test && pnpm e2e` green.
- Navigating a real page updates its sidebar title and favicon.
- Cmd+T / Cmd+W / Cmd+1..9 work in the running app.
- CI green on the merge request branch.
